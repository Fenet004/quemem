# Quemem Formation Backend

This is the backend for the Quemem Formation project, built with NestJS. It handles user authentication, LLC formation requests, and payment processing.

## Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/quemem-formation-backend.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the server:
   ```sh
   npm run start
   ```
